# Boto

A personal Kanban app for macOS, written in Swift with SwiftUI and SwiftData. Local-first: projects, cards, hours and backups stay on your Mac.

- Build and run: `./Scripts/make-app.sh`, then open `build/Boto.app`.
- Tests: `swift test`.
- Requires macOS 14 or later.
